# Actual playing-date forecasts

`TemporalGraphConfig(forecast_policy='actual_playing_date_v1')` uses the local midnight beginning each fixture's actual playing date. It ignores original round anchors, including for postponed fixtures; nullable original-round labels are permitted. Issuance must agree with the authoritative schedule's actual kickoff and cannot be overridden by an old round timestamp. Results use actual kickoff as an explicit retrospective availability proxy. Later reviewed release bounds remain binding, and result/statistic availability and fitting/selection boundaries are strict-before.

This mode is separate from the unchanged `by_round` and `one_day_ahead` behavior and old research profiles. New factories `GATActualDateBNV1`, `GATActualDateCE1V1`, and `GATActualDateBCDDWV1` include all six shots/corners coordinates. Explicit source/config identities prevent reusing earlier context or checkpoints under changed timing. Midnight issuance also keeps membership, observed gaps and age weighting at the same instant as graph history. DST uses calendar normalization rather than subtracting 24 hours.

The workbook preparation and fixed protocol are in `examples/workbook_actual_date`. This is a different experiment from the older native-source baseline. Its observed-member form-rank policy is separately versioned; countdown is explicitly missing because no historical schedule-publication log is available. Read the protocol's limitations before interpreting B/CD_DW or comparing to older results. The workbook's unknown timezone is handled by a declared Berlin civil-clock convention, with repeated-hour UTC candidates retained in audit. No original-round values are replaced by playing-date cohort numbers.

Tests cover postponements, intervening results, same-day exclusion, daylight-saving transitions, stale schedule/issuance rejection, exact release boundaries, future-result/team perturbations, unknown stages, phase-source persistence and unchanged older modes. Combined regressions cover CPU/CUDA neural preparation, persistence, deterministic updates, statistics, phase features and observed gaps. The experiment additionally checks every stage/fold and all nine family/stage CUDA smoke cases before sealing.
